# I'm sosharpyard 👋

I write Python and Go at work, then come home and tinker with the same tools in different configurations. Most of my open-source work sits at the intersection of developer ergonomics and minimalism, because I genuinely believe most software tries to do too much. Lately I've been interested in how small, composable pieces — a Neovim plugin, a Docker image, a well-named function — can quietly make someone else's Tuesday afternoon a little less frustrating.
